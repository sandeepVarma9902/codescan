Data practices

Privacy Policy

Effective September 11, 2026

Data processed

The service processes account identifiers, repository metadata, source code supplied for migration, job events, verification reports, billing references, and security audit records. Payment card details are handled by the configured payment provider and are not stored by Repo Upgrader.

Purpose

Data is used to authenticate customers, perform migrations, deliver results, enforce plans, prevent abuse, provide support, and improve aggregate reliability. Customer repository names and source code are never placed in marketing drafts.

Retention and deletion

Plan-specific report retention is displayed in the account dashboard. Disposable worker copies should be deleted after delivery. Production operators must configure durable storage lifecycle rules, backups, and a verified deletion-request process before public sale.

Sharing and transfers

Data may be processed by configured infrastructure, GitHub, storage, monitoring, and payment providers solely to operate the service. A production subprocessor list and cross-border transfer terms must be published for the chosen deployment.

Security

Controls include tenant-scoped authorization, hashed API credentials, signed webhooks, isolated execution, audit evidence, and encrypted external report storage when configured. No system can guarantee absolute security.

Your choices

Customers may request access, correction, export, or deletion through the production support contact, subject to legal and security retention duties. The operator’s business identity and support email must be configured before public payments are enabled.
